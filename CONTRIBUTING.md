# Contributing

haste does not accept pull requests yet. Its internals and command line
still change often.

Report bugs and request features in
[issues](https://github.com/manaforged/haste/issues). For a bug, include:

- the `haste` command you ran and its full output;
- the Rust toolchain version (`rustc --version`);
- a small project that reproduces the problem, with its `Cargo.lock`.
